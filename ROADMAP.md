# Дорожная карта шахматного тренера

Цель: помогать учиться играть — замечать угрозы, понимать причины ходов, исправлять ошибки и применять приём в незнакомой позиции.

## Фактическая основа
Проверено на main на 6 ноября 2026: опубликована 0.11.0.
Есть PGN файлом/текстом, ограниченное распознавание видео, локальный Stockfish, сравнение двух ходов при одинаковом лимите, объяснения и стрелки, тренировка на своих позициях, повторение по расписанию внутри приложения, общая очередь по истории.
Это веб-приложение/PWA. Отдельного приложения в App Store и подтверждения работы на физическом iPhone нет.
Обновление: GitHub Pages + колокольчик. Данные партий/прогресса остаются на устройстве.

## Следующие задачи — выбирать сверху
Новые замечания владельца и подтверждённые поломки имеют приоритет. Отмечать готовность только после проверок и, для релиза приложения, проверки публикации.

### 1. Надёжное сохранение обучения — следующая задача
- [ ] Резервная копия партий, оценок и учебного прогресса одним локальным файлом.
- [ ] Проверка формата и версии копии до восстановления; понятный результат без частично применённых данных.
- [ ] Предварительный просмотр количества партий и выбор безопасного объединения. Не перезаписывать существующее молча.
- [ ] Проверки: перенос прогресса/сравнений, старые записи, дубли, повреждённый/чужой файл, ошибка записи и сохранность исходных данных.
Готово, когда пользователь может восстановить обучение после смены устройства или очистки браузера, а не только выгрузить ходы PGN.

### 2. Понимание приёма на новой позиции
- [ ] Короткое объяснение выбранной темы с одним наглядным примером.
- [ ] После своей ошибки — другая проверенная позиция на тот же приём.
- [ ] Начать с безопасности короля и защиты фигур; затем связки и двойные нападения.
- [ ] Все ходы и ответы проверять; открытые наборы использовать только после проверки источника и лицензии. Не выдавать случайно сгенерированные позиции за качественные учебные задачи.
- [ ] Принимать законные равноценные альтернативы; отделять подсказку от самостоятельной попытки.
Готово, когда нужно распознать идею в новой ситуации, а не вспомнить клетку из своей партии.

### 3. Более понятная обратная связь
- [ ] По возможности сопоставлять две конкретные задачи ходов и один ответ соперника.
- [ ] Улучшать покрытие потери защиты, разменов и вскрытых нападений на наборе проверяемых примеров.
- [ ] Если причина не установлена, честно писать об этом вместо общих фраз про ухудшение оценки.
- [ ] Убирать повтор текста и технические подробности, не полезные ученику.

### 4. Проверка переноса навыка в новые партии
- [ ] Отдельно показывать самостоятельные решения, решения с помощью и незнакомые проверочные задачи.
- [ ] Сравнивать повторения изученных тем в последующих партиях с понятными знаменателями и отметкой нехватки данных.
- [ ] Не обещать причинный эффект обучения или рост Elo по нескольким задачам.

### 5. Надёжность и iPhone
- [ ] Укреплять восстановление полной партии из видео; спорные/неполные участки не скрывать.
- [ ] Проверять обновления, офлайн-запуск, хранение и долгие расчёты.
- [ ] Проверить на физическом Safari/PWA при наличии устройства/доступа; до этого не заявлять такую проверку.
- [ ] Нативную оболочку/распространение рассматривать после стабильного обучения; платные аккаунты и App Store — отдельное решение владельца.

## Как вести статус
За один запуск доводить до готовности один небольшой проверяемый шаг. Крупную задачу можно разделить, но нельзя закрывать её целиком за частичную реализацию.
Добавлять здесь запись: дата, выполненная часть, PR, версия (если был релиз), проверки, оставшееся. Не вести фиктивный журнал автономных запусков.
