# Проверка импорта видео

## Алгоритм

- Приём позиции только после двух последовательных уверенных распознаваний.
- Сначала проверяется один легальный ход; затем ищется единственная точная последовательность из двух полуходов. При исчерпании лимита 4096 вариантов результат поиска полностью отклоняется.
- Старая просмотренная позиция не используется для отката цепочки.
- Восстановленные ходы помечаются для проверки: известно время соседних наблюдений, а не точное время пропущенного хода.
- Перед Stockfish доступны список ходов, экспорт PGN, предупреждения и подтверждение анализа.
- Начальный анализ оценивает каждую позицию без принудительного продления вариантов. Углубление выбранной позиции сохранено.

## Автоматические проверки

Команда: `node --test tests/*.test.mjs`.

Синтетические тесты покрывают пропуск промежуточной позиции, одиночный кадр, плохое качество, длинный пропуск, показ исторической позиции, рокировку и исчерпание лимита поиска. Эти проверки подтверждают программную логику, а не точность классификации изображения.

## Перед публикацией

Браузерный прогон не завершён: Chromium в рабочей среде отсутствует; скачанный установщиком Playwright архив повреждён.

Проверить в браузере: видео → предпросмотр ходов → экспорт PGN → отмена/повтор → Stockfish → сохранение → повторное открытие. Отдельно проверить Safari на iPhone, PWA-кэш нового модуля и обновление без потери истории.

Неподвижная доска в конце записи не доказывает пропуск ходов. Подтверждать полноту распознавания нужно сравнением с независимым эталонным PGN. Видеофайлы, кадры, позиции, полученные из пользовательских записей, и частные PGN не входят в публичный репозиторий.
