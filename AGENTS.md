# Инструкции ИИ-разработчику — Шахматное ателье

## Назначение
Статическое клиентское шахматное приложение: импорт PGN, распознавание экрана шахматной доски на поддерживаемых видео, анализ Stockfish, график оценки, альтернативные варианты и PWA для iPhone. Личные партии и видео остаются на устройстве.

## Карта проекта
- `dist/index.html`, `dist/style.css`, `dist/app.js`: интерфейс и логика;
- `dist/chess.js`, `dist/stockfish-19-lite-single.*`, `dist/recognizer.js`: шахматные правила, движок и распознавание;
- `dist/openings.json`, `dist/templates*.json`, `dist/samples.json`: данные и примеры;
- `dist/sw.js`, `dist/manifest.webmanifest`, `dist/version.json`: PWA и обновления;
- `.github/workflows/pages.yml`: публикация при push в main с подстановкой версии/коммита;
- `README.md`, `LICENSE`, `dist/licenses.html`: назначение и лицензирование GPL-3.0-or-later.

## Не ломать
- Работа PGN, ходов, возврата к партии и честная оценка Stockfish с оговоркой о глубине.
- Офлайн-обработку партий и видео, отсутствие передачи пользовательских записей наружу.
- Кэш service worker и уведомление об обновлении; не путать содержимое исходного `dist/version.json` с генерируемым во время Pages deploy.
- Лицензии сторонних библиотек и двигателей; не заменять артефакты без проверки совместимости.
- Не обещать распознавание всех тем Chess.com: текущее видео-распознавание ограничено конкретным типом записи.

## Проверка
- Локально: `python3 -m http.server 8000 --directory dist`, открыть `http://localhost:8000`.
- Вручную: импорт PGN, прокрутка ходов, оценка каждого хода, лучшие варианты, возврат к партии, экспорт PGN; отдельно проверка распознавания на обезличенном эталонном видео.
- На iPhone/Safari: установка PWA, повторный запуск, offline-поведение, обновление service worker без потери истории. Сейчас отдельного набора автоматических тестов в корне репозитория не обнаружено: не писать «тесты пройдены» без результата.

## Процесс и публикация
Полный mini-pipeline `DEVELOPMENT.md` только по явному запросу. Отдельная ветка → PR → ручные проверки → решение владельца. **Не сливать PR без разрешения:** push в main запускает публикацию GitHub Pages. Не менять опубликованную версию без отдельной задачи.
