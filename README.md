# Шахматное ателье

Мобильное веб-приложение для разбора шахматных партий по записи экрана или PGN.

## Что должно уметь приложение

- Восстанавливать ходы из видео и давать пользователю исправить сомнительные распознанные позиции.
- Показывать все ходы партии с понятной оценкой: сильный ход, хороший ход, неточность, ошибка или грубая ошибка.
- Для каждого проблемного хода объяснять, что сыграно, как лучше было сыграть и почему.
- Показывать отдельный вариант улучшения на доске с ответами соперника на 5–10 ходов.
- Давать понятный переход между «Моей партией» и «Как лучше сыграть», чтобы можно было вернуться к реальным ходам.
- Определять дебюты и отмечать точные совпадения с известными гамбитами.
- Выполнять анализ на устройстве с помощью Stockfish, когда это возможно.
