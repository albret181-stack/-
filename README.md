# Шахматное ателье

Личный шахматный тренер для разбора своих партий и обучения на ошибках. Статическая папка `dist/` публикуется на GitHub Pages при обновлении ветки `main`.

[Открыть приложение](https://albret181-stack.github.io/-/) · [План развития](ROADMAP.md) · [Рабочий порядок](AGENTS.md)

## Что есть в 0.11.0
- Импорт PGN файлом или текстом и выбор своей стороны.
- Распознавание вертикального видео зелёной доски Chess.com; найденные ходы можно проверить и исправить перед анализом. Распознавание может быть неполным.
- Локальный Stockfish 19 Lite, оценки ходов и перепроверка двух кандидатов из одной позиции при одинаковом лимите поиска.
- Объяснения тактических и позиционных различий, стрелки перемещения/нападения/контроля и выделение выбранного пояснения.
- Компактный просмотр своей партии с навигацией. Основное сравнение показывает один более сильный ход, а не длинное дерево продолжений.
- Итог партии, тренировка на своих позициях, проверка альтернатив и один подтверждённый ответ соперника после неудачной попытки.
- Повторение внутри приложения и общая учебная очередь по сохранённым партиям. Число решений не является оценкой Elo.
- Экспорт ходов в PGN, локальная история и PWA. Полная резервная копия обучения — следующий пункт дорожной карты.

Видео, партии и учебные результаты обрабатываются в браузере и остаются на устройстве. Не очищайте данные сайта, если хотите сохранить историю: PGN содержит ходы, но не все оценки и прогресс.

## Запуск
Из корня репозитория:
```sh
python3 -m http.server 8000 --directory dist
```
Откройте `http://localhost:8000`. Для установки PWA нужен HTTPS.
Оценки предварительные; ограниченный расчёт не доказывает абсолютную оптимальность. Текст строится по проверяемым признакам позиции без зависимости от GPT.

## iPhone и обновления
Откройте приложение в Safari и используйте «Поделиться» → «На экран Домой» для установки PWA. Это не отдельное приложение в App Store.
Колокольчик проверяет опубликованный `version.json`; кнопка обновления устанавливает новую сборку через service worker. Физический iPhone/Safari не считается проверенным по одному тесту мобильной ширины браузера.

Для первой публикации GitHub Pages нужен источник **GitHub Actions** в Settings → Pages. Последующие публикации выполняет `.github/workflows/pages.yml`.

## Разработка и проверки
Самостоятельный цикл описан в [AGENTS.md](AGENTS.md), следующая задача — в [ROADMAP.md](ROADMAP.md). Расписание запусков настраивается отдельно от исходного кода; эти файлы сами по себе не запускают агента в фоне.
- Логика: `node --test tests/*.test.mjs`.
- Браузерные сценарии с синтетическим видео и настоящим Stockfish: `.github/workflows/checks.yml`.
- Более ранние материалы по распознаванию: [docs/VIDEO_IMPORT_CHECK.md](docs/VIDEO_IMPORT_CHECK.md). Старые записи описывают соответствующую версию, не текущий интерфейс.
