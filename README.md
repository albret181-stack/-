# Шахматное ателье

Личное шахматное веб-приложение для разбора записей партий. Статическая папка `dist/` публикуется на GitHub Pages автоматически при каждом обновлении ветки `main`.

## Возможности

- Импорт PGN и распознавание видео с зелёной доской Chess.com.
- Локальный Stockfish 19 Lite: оценка каждого хода, ошибки и продолжения до 20 полуходов.
- Переключение между ходами исходной партии и расчётным вариантом, с явной кнопкой возврата к партии.
- Определение дебюта, экспорт PGN, локальная история и PWA.
- Видео и пользовательские партии обрабатываются в браузере и остаются на устройстве. Публичный репозиторий содержит приложение без ваших личных партий и исходных записей.

## Запуск локально

Из корня репозитория:

```sh
python -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Для установки PWA нужен HTTPS.

Оценки движка предварительные и могут измениться при более глубоком расчёте. Функция распознавания видео сейчас настроена на вертикальную запись зелёной доски Chess.com с начала партии.
