# Шахматное ателье

Личное шахматное веб-приложение для разбора записей партий. Статическая папка `dist/` публикуется на GitHub Pages автоматически при каждом обновлении ветки `main`.

## Возможности

- Импорт PGN и распознавание видео с зелёной доской Chess.com, с отдельным статусом распознанных ходов и оценённых движком позиций.
- Локальный Stockfish 19 Lite: оценка каждого хода, ошибки и продолжения до 20 полуходов.
- Показ оценки каждого хода; сравнение сыгранной линии с альтернативой движка и кнопка возврата к партии.
- Определение дебюта, экспорт PGN, локальная история и PWA.
- Видео и пользовательские партии обрабатываются в браузере и остаются на устройстве. Публичный репозиторий содержит приложение без ваших личных партий и исходных записей.

## Запуск локально

Из корня репозитория:

```sh
python -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Для установки PWA нужен HTTPS.

Оценки движка предварительные и могут измениться при более глубоком расчёте. Функция распознавания видео сейчас настроена на вертикальную запись зелёной доски Chess.com с начала партии.

Приложение распространяется по GPL-3.0-or-later. Лицензии библиотек и движка доступны в `dist/licenses.html`.

## iPhone и обновления

После первой публикации откройте GitHub Pages в Safari на iPhone, нажмите «Поделиться» → «На экран Домой» и включите «Открывать как веб-приложение». Колокольчик проверяет последнюю сборку GitHub Pages; кнопка «Обновить приложение» устанавливает её через service worker. Каждое обновление ветки `main` запускает публикацию новой сборки.

Для первой публикации один раз включите **Settings → Pages → Build and deployment → Source: GitHub Actions**. После этого публикация и проверка обновлений работают автоматически.

## Проверка распознавания перед анализом (0.3.2)

После обработки видео приложение показывает все найденные ходы. Их можно скачать в PGN до запуска Stockfish. Время последнего хода не равно длительности просмотренной записи: в конце видео доска может долго оставаться неподвижной, а сама запись может закончиться до конца игры.

Пропуск одной промежуточной позиции восстанавливается только при единственной точной легальной последовательности из двух полуходов. Эти ходы отмечаются звёздочкой; известен интервал пропуска, а не точное время каждого хода. Более длинные и неоднозначные пропуски остаются для проверки. Поиск ограничен 4096 вариантами.

Первичный Stockfish оценивает каждую восстановленную позицию без принудительного продления каждой линии. Для выбранного хода остаётся кнопка «Углубить расчёт».

Проверки логики: `node --test tests/*.test.mjs`.
